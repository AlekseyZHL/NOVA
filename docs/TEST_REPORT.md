## 4. Внешние ограничения (не дефекты продукта)

- **Solana Devnet faucet:** `requestAirdrop` возвращает `429 — you've either reached your airdrop limit today or the faucet has run dry`. Публичный кран исчерпан/ограничен по IP. Приложение корректно переключается на ручной режим (адрес + ссылка на `faucet.solana.com`).
- **Solana Testnet cluster:** `-32603 Internal error`.
- **mempool.space Testnet4 faucet:** требует hCaptcha; обход капчи сознательно не реализовывался.
- **Polygon Amoy RPC:** `rpc-amoy.polygon.technology` не отвечал; заменён на `polygon-amoy-bor-rpc.publicnode.com` (chainId 80002 подтверждён).
- **Вывод:** код подписи и трансляции готов и проверен офлайн-подписями; для сквозной ончейн-транзакции нужен финансируемый тестнет-адрес (свой RPC/кран) — после пополнения путь `/simulate → /send` сработает без изменений.
