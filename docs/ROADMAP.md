# Дорожная карта: как реально «переплюнуть всех» по удобству

Текущая версия — крепкий фундамент. Ниже — приоритизированный план, где каждый пункт привязан к конкретной пользовательской боли. Оценки — ориентир для одного разработчика при наличии ключей API.

## P0 — перед любым mainnet (безопасность)

| # | Задача | Боль | Сложность |
|---|---|---|---|
| 1 | Независимый аудит + пентест | Деньги пользователей | 3–4 нед |
| 2 | KMS/HSM и вынос подписи в изолированный воркер | Один сервер = одна точка кражи | 2 нед |
| 3 | PostgreSQL + Redis, миграция с JSON | Потеря данных, масштаб | 1 нед |
| 4 | Rate limiting, WAF, мониторинг, circuit breaker | DoS и массовые выводы | 1 нед |
| 5 | MPC / пороговая подпись вместо одного seed | Компрометация master seed | 3–4 нед |
| 6 | Юркомплаенс: KYC/AML, соглашение, GDPR, лицензии | Кастодиальный сервис вне закона | — |

## P3 — инфраструктура и доверие

- Собственные ноды или выделенные VPC-эндпоинты вместо публичных RPC.
- SLA 99.9%, статус-страница, баунти-программа.
- Страховой фонд / партнёрская страховка депозитов.
- Открытый SDK и README для интеграторов.
- Регулярные отчёты по безопасности.

## Критерий успеха

> Пользователь открывает кошелёк впервые и за **60 секунд** получает первый актив и понимает, куда нажать. Ни одного поля с сид-фразой, ни одной комиссии «вслепую», ни одного адреса, который нужно переписывать вручную.

Именно под этот критерий следует оптимизировать каждый пункт выше.
